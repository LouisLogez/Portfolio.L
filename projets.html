Compétition

Hackagou 2025 – Capture The Flag

Participation à un CTF de cybersécurité avec ma classe sur le thème « Apocalypse : une IA devenue folle menace l’humanité ». Épreuves de cryptographie, d’analyse réseau et de rétro-ingénierie à résoudre en temps limité.

  • Résultat : 3e place au classement général (équipe « DevOps »)
  • Compétences : analyse, résolution de problèmes, travail sous pression
Cybersécurité CTF
À compléter : détaille une épreuve que tu as résolue — l’énoncé, ta démarche, l’outil utilisé, le flag obtenu. Un jury retiendra bien plus un challenge raconté précisément que la mention d’un classement.
Projet scolaire

Le Pendu numérique

Conception et développement d’un jeu interactif pour la Semaine du numérique du lycée 2025. Le joueur doit deviner toutes les lettres d’un mot avant la fin de ses essais.

  • Technologies : Python, HTML, CSS
  • Compétences : logique de programmation, gestion d’état, interface utilisateur
Développement Semaine du numérique 2025
À préciser : « Python + HTML/CSS » est ambigu. Indique l’architecture réelle : script Python en console ? interface web avec Flask ? Pygame ? Ajoute un lien vers le dépôt GitHub et un extrait de code commenté (par exemple la boucle de jeu ou la validation d’une lettre).
